Rosy Retail · setup guide

About 30 minutes, one time. Do it on a computer if you can. Parts 1–2 are on the Firebase website, part 3 on GitHub, part 4 on the phones.

In the zip you have: index.html (the app), sw.js (lets it open without internet), manifest.json, icon-192.png, icon-512.png, firestore.rules and this guide.

1Make the free cloud database (Firebase)

  1. Open console.firebase.google.com and log in with your Google account.
  2. Tap Create a project (or "Add project"). Name: rosy-retail. Turn Google Analytics off. Tap Create project.
  3. On the left: Build → Authentication → Get started. Open the Sign-in method tab, choose Anonymous, switch it on, tap Save.
  4. On the left: Build → Firestore Database → Create database.
    • If it asks for an edition, keep Standard.
    • Location: asia-south1 (Mumbai). This cannot be changed later.
    • Choose Start in production mode, then Create.
  5. In Firestore, open the Rules tab. Delete what is there, paste this, and tap Publish: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}

2Copy your Firebase settings

  1. Tap the gear icon → Project settings. Scroll to Your apps and tap the </> (Web) button.
  2. App nickname: rosy web. Leave "Firebase Hosting" unticked. Tap Register app.
  3. You will see a block like this. Copy the part between the { }: 
    const firebaseConfig = {
  apiKey: "AIza....",
  authDomain: "rosy-retail-xxxx.firebaseapp.com",
  projectId: "rosy-retail-xxxx",
  storageBucket: "rosy-retail-xxxx.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcd..."
};
  4. Open index.html in Notepad. Find the line window.FIREBASE_CONFIG = null; and change it to your settings, like this: 
    window.FIREBASE_CONFIG = {
  apiKey: "AIza....",
  authDomain: "rosy-retail-xxxx.firebaseapp.com",
  projectId: "rosy-retail-xxxx",
  storageBucket: "rosy-retail-xxxx.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcd..."
};
    Save the file.
Skipped this step? That's fine too. The app will ask for these settings the first time it opens. Paste the same block there once on the owner phone, then use Settings → Sync & devices → Copy link to connect the other phones.

3Put the app online (GitHub Pages, free)

  1. Open github.com and log in (the same account as your SALESPOS page).
  2. Tap + → New repository. Name: rosy-retail. Keep it Public. Tap Create repository.
  3. Tap uploading an existing file. Drag in index.html, sw.js, manifest.json, icon-192.png, icon-512.png. Tap Commit changes.
  4. Open the repository's Settings → Pages. Under "Branch" choose main and / (root), then Save.
  5. Wait 1–2 minutes. Your app link will be:
    https://mahendra41098.github.io/rosy-retail/
To update the app later, upload the new index.html the same way. Phones pick up the new version the next time they open it with internet.

4Set up the phones

Owner phone first

  1. Open the link in Chrome. Tap Owner view and enter the owner PIN.
  2. Chrome menu (⋮) → Add to Home screen / Install app.
  3. Go to More → Settings and do these once:
    • Login PINs: tap Show all, then change every PIN (pencil).
    • Staff: add each person's name, mobile, 4-digit PIN and target. Switch business at the top and repeat for each shop.
    • Shop details: address, contact number, GSTIN, bill note and printer paper for each shop.
  4. Check More → Categories & items for each shop and add, rename or delete as you like.

Each shop phone

  1. Open the app link in Chrome (or the link from Settings → Sync & devices → Copy link, sent on WhatsApp).
  2. Tap the shop (Rosy, Pinky Collection or Cmore), enter that shop's PIN.
  3. Chrome menu → Install app. From now on staff open it from the home screen.
  4. It stays logged in. Logging out needs the shop PIN or the owner PIN.

5Printing bills

  1. For a Bluetooth bill printer, install RawBT (Play Store) on the shop phone and pair the printer in it.
  2. In the app tap Print bill → Print. In Android's print screen choose RawBT (or your printer) as the printer.
  3. Set the paper size (2 or 3 inch) for each shop in Settings → Shop details.

6Good to know

  • Live sync: a bill saved on any phone appears on every other phone, including yours, within about a second.
  • No internet: bills save on the phone and go up by themselves when the internet is back. The top pill shows "Offline · bills saved on phone". Each phone needs internet the very first time it opens the app.
  • Free plan limits: Firebase's free plan gives 20,000 saves and 50,000 reads a day and 1 GB of storage. A bill uses about 5 saves, so even 1,000 bills a day is fine. Photos use the most space: roughly 100 KB each, so around 8,000–10,000 photos fit. Keep photos optional unless you need them.
  • Bill numbers restart each financial year: ROSY/26-27/000001. If two phones bill the same shop at the same moment while offline, they could get the same number. With one phone per shop this does not happen.
  • Backup: Owner → Sales → pick a month → Export gives an Excel (CSV) file. Books → Export gives the year's month-wise totals.
About security. The PINs stop staff from opening the owner view in the app. But the data itself is protected only by "must be using the app", and the app link is public. Someone technical who has the link could read the data, including purchase costs, with browser tools. Don't share the link outside your shops. If you want stronger protection later (a separate login for each shop and owner-only access to costs), I can add it.
